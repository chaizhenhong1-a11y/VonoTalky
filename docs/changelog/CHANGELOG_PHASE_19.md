# VonoTalky Phase 19 — Group Message Search

## Added
- Search button in the group-chat app bar.
- Keyword search across group messages.
- Sender-name search.
- File-name search.
- Filters for All, Text, Photos, Files and Voice.
- Keyword highlighting in result previews.
- Sender, type and date/time shown in results.
- Tapping a result returns to the group chat and jumps to the original message.

## Compatibility
- Continues directly from Phase 18.
- No new Flutter packages.
- No Firestore Rules changes.
- No schema migration.
